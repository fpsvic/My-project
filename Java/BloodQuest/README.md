# Blood Quest Java

Standalone Java/Swing rewrite of the Blood Quest gothic platformer.

## Run

Launch it as a desktop app:

```bash
cd Java/BloodQuest
./run-desktop.sh
```

Optional Linux desktop/menu shortcut:

```bash
cd Java/BloodQuest
./install-desktop-launcher.sh
```

Manual compile/run:

```bash
cd Java/BloodQuest
javac BloodQuest.java
java BloodQuest
```

## Controls

- `A` / `D` or arrow keys: move
- `W`, `Space`, or up arrow: jump
- `P` or `Esc`: pause/resume
- `M`: mute/unmute synthesized sound
- `Enter`: activate the current menu action
